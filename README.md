安装
```
git clone https://gitee.com/dungeonmaster/kkp-plugin.git ./plugins/kkp-plugin/
```
安装依赖
```
pnpm add axios -w
```
为了防止风控，所以得安装python来处理图片

安装python依赖
```
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pillow
```
